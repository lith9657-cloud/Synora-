## الرقم الصادق
النموذج يعيد تركيب مادة أقل نسخاً وأكثر سلاسة وينتج تسلسلات جديدة
بنسبة أعلى، لكنه **لا يجيب موضوعياً عن أسئلة الحوار** بالبيانات
المرخصة القابلة للوصول اليوم. المسارات المفتوحة: مصدر حوار عربي
مرخص بحجم حقيقي (فحص 20 نوفمبر لم يجد واحداً)، أو تأليف أزواج
عربية 3-5MB، أو معمارية بتعميم. تفاصيل القياس في RESULTS_FIX4.md
ودور fix7، وبوابة G1 في `tools/g1_generation.py`.

## التشغيل
`SYNORA_STATE_DIR=<مسار state_clean> PYTHONPATH=. python3 -c
"from pcm.server import serve; serve().serve_forever()"`
الأدوات والاختبارات في `tools/`، السجلات في `logs/`، كل جدول أعلاه
قابل لإعادة التشغيل منها. ملاحظة التشغيل: بناء نسخة جديدة بحجم
17MB يتجاوز ذاكرة بيئة التشغيل في العملية نفسها — استخدم الحالة
المرفقة جاهزة أو بنِ في عملية مستقلة بلا تحقق داخلي.

## تحديث fix17 (21 نوفمبر 2026): طبقة الفهم العصبية — التركيبة 20/60/10

قرار المالك: تعديل القيد المؤسسي — طبقة فهم عصبية صغيرة (20٪) تُلحق أي صيغة أو لهجة
بالمعيار الذي يخدمه القلب العددي (60٪)، مع قواعد رمزية للحساب والهوية (10٪). الطبقة
تفهم فقط ولا تولّد؛ القلب العددي يبقى صاحب الجواب والحساب والذاكرة.

- المُشفّر: `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` (Apache-2.0)
  مُكمَّم int8 (235MB) في `neural/`، مع تبييض جزئي ورأس تبايني مدرَّب على 6502 زوجاً
  لهجياً مركّباً من قواعد المشروع (بنك اللهجات الـ150 محجوز تماماً للاختبار).
- الدمج إضافي آمن: KB-first (عصبي يقترح، عدّ IDF يحكم عند التعارض، وتجاوز التطابق
  التام) + إنقاذ ما سقط من البوابات بصياغة معيارية واحدة واثقة.
- النتائج: بنك اللهجات 111/150 → 136/150 (الرياضيات 20→40/40 كاملة، الحقائق 40/40)،
  bench400 = 400/400، bench400v2 = 400/400، بطارية الحوار مطابقة. التفاصيل الكاملة
  والقيود الصادقة: `RESULTS_FIX17.md` و`neural/NEURAL_LAYER.md`.
- المتطلبات الجديدة للتشغيل: torch (CPU) + tokenizers + numpy — والطبقة تعطل بأمان
  (المحرك يعمل رمزياً) إن غابت.
