# دليل نشر سينورا — README_DEPLOY.md

## الخيار 1: استضافة ثابتة مجانية (وضع تجريبي — دقيقتان)

الواجهة ملف واحد ذاتي الاكتفاء يعمل على أي استضافة ثابتة، وفيها **محرك تجريبي محلي داخل المتصفح** (رياضيات + بنك معرفة صغير + مولّد المواقع كامل):

1. ارفع `index.html` وحده إلى:
   - **Netlify Drop**: افتح app.netlify.com/drop وأفلت الملف → رابط فوري للناس.
   - **GitHub Pages**: ارفعه لمستودع باسم your-name.github.io.
   - **Vercel / Cloudflare Pages**: نفس الفكرة (Static).
2. شارك الرابط — الناس يجربون الدردشة التجريبية وباني المواقع فوراً (شارة «وضع تجريبي» ظاهرة أعلى الصفحة).

## الخيار 2: المحرك الكامل مجاناً (بدون شارة تجريبية)

- **Hugging Face Spaces** (الأفضل للمحرك): أنشئ Space نوع Docker/Gradio، ارفع `synora19_web/` + `synora16_model_clean/`، وشغّل:
  `python synora_server.py 7860`
  متطلبات: `numpy` + `tokenizers` فقط.
- **PythonAnywhere**: ارفع المجلدين، Web app → manual config → `synora_server.py`.
- **Render / Railway (free tier)**: نفس الأمر، منفذ من متغير البيئة `$PORT`.

تشغيل محلي: `python synora_server.py 8000` ثم افتح `http://localhost:8000`.

## بنية الملفات للنشر الكامل
```
synora19_web/
  index.html            ← الواجهة (ملف واحد)
  synora_server.py      ← سيرفر بلا اعتماديات
  README_DEPLOY.md      ← هذا الملف
synora16_model_clean/   ← حزمة المحرك (بجانب المجلد)
  tools/ … neural/ … lm/
```

## تشغيل الواجهة واختبارها
- تبويب «الدردشة»: أسئلة رياضيات/برمجة/حقائق بالعربية أو الإنجليزية.
- تبويب «بناء المواقع»: اختر النوع + الاسم + الهوية اللونية → «ابنِ الموقع الآن» → معاينة حية (سطح مكتب/جوال) → «فتح في تبويب» أو «تحميل HTML».

## لاحقاً (مراحل متقدمة)
عند رفعه على منصات API للنماذج: الواجهة جاهزة — بدّل نقطة `/api/chat` إلى بوابة الـAPI في متغير `API_OK` داخل index.html، بلا تغيير في التصميم.
